# Ejercicio guiado

Este segundo módulo existe para mostrar cómo se ordenan varios módulos: la
carpeta `02-practica` va después de `01-fundamentos` por su prefijo numérico.

Duplica esta carpeta para añadir más módulos, renumerándola según el orden
que quieras (`03-`, `04-`, ...).
